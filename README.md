# ABIRGroup — נתוני מפת הסיכונים הפיננסיים

המאגר מכיל קובץ אחד, `risks.json`, שמוצג במפת הסיכונים באתר [abirgroup.com](https://abirgroup.com).
הקובץ מתעדכן אוטומטית ממאגר פרטי, אחרי בדיקה ואישור. אין לערוך אותו כאן ידנית.

**הבהרה:** אין האמור מהווה ייעוץ פיננסי, ייעוץ השקעות, שיווק השקעות או המלצה מכל סוג שהוא, ואין להסתמך עליו בקבלת החלטות השקעה או החלטות כלשהן. הנתונים הם סיכום עריכתי של פרסומים ציבוריים, והציונים משקפים הערכה סובייקטיבית של קבוצת אביר. השימוש במידע הוא על אחריות המשתמש בלבד.
